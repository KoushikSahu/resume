\begin{itemize}
	\item Blogging platform allowing users to share ideas and opinion on subject of their choice
	\item Frontend is fully responsive and written in using react and styled with bootstrap
	\item Backend is written in python using django and djangorestframework
	\item Allows user authentication using JSON Web Token(JWT)
	\item User data is stored in sqlite database
